# Contributing

This is a proposal under active community review at the OpenTelemetry SIG GenAI tracker.

How to engage:

1. Read the attribute definitions in `registry/agent.yaml` and `registry/fga.yaml`.
2. Run the reference implementation. The AIM backend at https://github.com/opena2a-org/agent-identity-management emits these attributes today.
3. Try the LangChain example at `examples/langchain.py` against your own agent.
4. File issues here for repo-specific feedback. File issues on the OTel SemConv tracker for spec-level feedback.
5. Pull requests welcome. By contributing you agree your contributions are licensed under Apache 2.0.
